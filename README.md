# Bookish


> In this project, I am creating an app that allows users to read, create or update their already created books. It allows users to comment and follow updates given by authors on the ssaid books. Users have a privat chat space where they can have direct contact with authors and also have a chat discuss spot to discuss books with other users.

## Built With

- Ruby v3.7.1
- Ruby on Rails version 7.0

## Getting Started

To get a local copy up and running follow these simple example steps.

### Prerequisites

- Ruby: 3.7.1
- Rails: 7.0
- Postgres: >=9.5
- Cloudinary (for access key and secret key to upload images in production environment)
- You can set up webpacker locally [here](https://github.com/rails/webpacker#installation)

### Setup

To test the BooksApp locally, you will need to clone the repository, navigate to it's containing directory, and run the following commands:



Clone the repository and follow the steps to run the app.
```
 git clone https://github.com/Temmarie/Bookish.git

```



Install gems with:

```
bundle install
```

Setup database with:

```
   rails db:create
   rails db:migrate
```



### Usage

Start server with:

```
    rails server
```

Open `http://localhost:3000/` in your browser.

### Run tests

```
    rpsec spec
```
